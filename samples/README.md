Welcome! This folder is a **sample knowledge base** used to try mdv. Every page is plain Markdown, so the
same files work for people *and* for AI agents.

> [!TIP]
> Select any word and press <kbd>H</kbd> to highlight every occurrence in its own color.
> Try it with **agent**, **context** and **review**.

## How we work

1. Write the context for the agent in a `.md` file next to the code.
2. Ask the agent to work from that file and to update it as it goes.
3. Review the result here, in clean reading mode — then press <kbd>Ctrl</kbd>+<kbd>E</kbd> to fix anything in VS Code.

- [x] Keep documents short and linked
- [x] Prefer Markdown over PDF or DOCX
- [ ] Add diagrams where a picture helps

> The best documentation is the one that is easy to open.
