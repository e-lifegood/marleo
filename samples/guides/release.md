# Release

How a version goes out.

## Checklist

- [x] CI is green on `main`
- [x] `CHANGELOG.md` updated
- [ ] Tag pushed: `git tag v0.1.0 && git push --tags`
- [ ] Release notes reviewed

## Rollback

If something goes wrong, re-publish the previous release and open an issue with the steps to reproduce.
